# Risk_analysis

### A tool to analyze the risk of credit card holders from the trained dataset.

#### Using React and FastAPI I had made a tool to analyze the risk of credit card holders.


### You can find all the code in the code folder. The code is divided into two parts: frontend and backend.
## Backend involves

backend/models.py : This file contains the model definition.
backend/train.py : This file trains the model.
backend/app.py : This file contains the API definition using FastAPI.
backend/model.pkl : This file contains the trained model.

## Frontend involves
It mainly involves React.js for building the user interface and making API calls to the backend.
By making components and using it in main App.jsx file.
